# Informe Café Conquistadores

Sitio estático de una sola página, listo para publicar en GitHub Pages, Vercel o Netlify.

## Publicación rápida

- **Vercel:** crear un nuevo proyecto e importar esta carpeta/repositorio. No requiere build command.
- **GitHub Pages:** subir el contenido a un repositorio y publicar desde la rama principal, carpeta raíz.
- **Vista local:** abrir `index.html` en el navegador.

## Exportación a PDF

Abrir el informe y usar el botón **Guardar / imprimir PDF**. El archivo incluye estilos de impresión para A4.

## Archivos

- `index.html`: reporte completo.
- `assets/brand-people.webp`: recurso visual de la landing.
- `assets/brand-coffee.webp`: recurso visual de la landing.
