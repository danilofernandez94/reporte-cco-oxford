# Reporte trimestral — Café Conquistadores

Desde **Grupo Oxford** presentamos este reporte trimestral de pauta digital de **Café Conquistadores**, correspondiente al período comprendido entre el **23 de abril y el 31 de julio de 2026**.

El informe reúne la información y los principales resultados obtenidos en **Meta Ads** y **Google Ads**, incluyendo el rendimiento general de las campañas, la generación de leads y los indicadores más relevantes del período.
